# Уточнения VTT — 2026-10-30

Рабочее задание: добавить администратору изменение ролей в группах; прозрачный туман ГМа с локальным ползунком (10% затемнения по умолчанию); анимацию разрешённых сервером бросков поверх стола для всех получателей; явное скрытие характеристик токена от игроков; исключение 0 HP из инициативы; устойчивый свёрнутый трекер.

Архитектура: сохраняем текущие комнату, серверную проекцию и React/Konva/Three. Не делаем отдельную рассылку результатов кубиков: используем уже авторизованную историю. GM-маска вычисляется только из доступной ему полной сцены, игрокам настройки прозрачности не отправляются. Явный hideStats имеет приоритет над владением и shareStats; менять его может только ГМ. Нулевые HP исключаются серверным reconcileCombat с сохранением корректного следующего хода.

1. Luna: admin API/UI ролей кампаний, проверки прав и последнего ГМа.
2. Тесты: нулевые HP, переход/окончание боя, приватность характеристик даже владельцу.
3. combat.ts/scene.ts/combat-panel.tsx: скрытие данных, 0 HP, интерфейс без доступа к скрытым полям.
4. fog.ts/table-canvas.tsx/fog-controls.tsx/table-app.tsx: обзор группы для ГМа, 10% маска, локальное сохранение ползунка.
5. dice-tray.tsx/dice-stage.tsx/table.css: независимый overlay на карте, очередь бросков, прозрачный фон, размер от контейнера, числовой результат.
6. table-app.tsx: компактный трекер с текущим ходом и раундом; панель остаётся смонтирована при закрытии, состояние открытия сохраняется локально.
7. Полный npm test, TypeScript, production build; локальная UI-проверка по возможности. Обновление knowledge и журнала. Публикация не запрошена.

# Общие рисунки, выделение и группы токенов

2026-10-28. Пользователь одобрил кисть с цветом/толщиной/стиранием, выделение рамкой и Shift+клик, постоянные группы «Склеить»/«Разъединить». Все участники могут пользоваться инструментами на доступной им сцене. Предыдущая задача: удаление/редактирование любых токенов и Delete, сохраняется в объёме.

Подход: расширить существующую схему сцены и общий Konva Canvas; сохранить WebSocket/D1/R2 архитектуру. Отдельный локальный слой рисования не подходит: рисунки должны быть видны всем и переживать перезагрузку. Группы хранятся как необязательный groupId токена. Перемещение группы — единый серверный move ведущего токена с общим смещением, атомарными границами/версиями и одной блокировкой движения. Выделение остаётся локальным.

Кисть рисует в координатах мира, фиксирует один штрих по завершении. Ластик удаляет целые штрихи по нажатию. Цвет и толщина доступны в панели; рисунки ниже токенов. СКМ/пробел приоритетнее кисти и выделения. Рамка начинается на пустом месте, Shift добавляет к выбору; клик без Shift выбирает токен/его группу. Перетаскивание выделенного токена сохраняет выделение; после «Склеить» любая фигура двигает всю группу с сохранением взаимных расстояний. Ctrl/Alt отключают привязку ведущей фигуры, границы ограничивают группу целиком. Несколько выбранных токенов можно удалить одним действием. Нельзя использовать скрытую сцену мастера или удалять движущуюся группу.

Ограничения: существующий внешний вид и тема; без новых зависимостей; старые сцены читаются; конечные состояния сохраняются атомарно; в текстовых полях/диалогах Delete не действует. Чекпоинты вне checkout, секреты/базы в исходники не попадают. После проверок собственные процессы завершаются. Публикация сайта и GitHub продолжает ранее разрешённую работу.

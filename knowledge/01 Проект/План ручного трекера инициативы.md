# План ручного трекера инициативы

## Назначение

По согласованному запросу пользователя убрать автобой. Заклинания в задачу не входят. Изменения локальные, публикация не разрешена.

## Выполненные пункты

- [x] Удалить форму атаки и команду combat-attack, сравнение с КД и применение урона атаки.
- [x] Сохранить инициативу d20 + модификатор, старт, следующий ход, раунд и завершение трекера. При ничьей порядок задаётся вручную; дополнительные автоматические перебросы отключены.
- [x] Сохранить HP, максимум HP, временные HP, КД, модификатор, владение, видимость и ручные эффекты/статусы.
- [x] Сохранить кнопки ручного урона и лечения, числовую установку временных HP. Урон по кнопке сначала расходует временные HP, лечение ограничено максимумом.
- [x] Отключить истечение и уменьшение длительности эффектов при переходах. Длительность и связанный статус эффекта — заметки; добавление/снятие эффекта не переключает статусы токена.
- [x] Итог инициативы вычислять при броске; изменение модификатора не переписывает уже выпавший результат.
- [x] При 0 HP исключать токены без владельца и токены владельца с ролью master. Владельцы с ролью player сохраняют запись даже при 0 HP. В модели стола совмещённая роль master,player проецируется как master; отдельной роли конкретного токена нет.
- [x] Сохранить совместимость старых сцен: прежние поля lastAttack/tieRoll читаются, атаки не исполняются и их прежний результат не показывается.

Удаление текущего участника выбирает следующего доступного, пустая очередь завершает трекер. Это обслуживание очереди, HP и эффекты при переходах не меняются. Общий лоток кубов сохраняется.

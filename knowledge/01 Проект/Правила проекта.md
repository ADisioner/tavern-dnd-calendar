# Правила проекта

Источник обязательных инструкций — [AGENTS.md рабочей папки](../../../AGENTS.md). Эта заметка служит краткой памяткой; при расхождениях применяются актуальные инструкции пользователя и AGENTS.md.

1. Работать локально до явного запроса новой публикации. Не загружать версии Sites, не менять размещение/DNS и не запускать публикационные помощники.
2. Отправка в GitHub требует отдельного явного запроса; разрешена только через подключённую интеграцию Codex. `git push` и GitHub CLI для загрузки запрещены.
3. Перед существенными изменениями сохранять датированный исходный checkpoint в `F:\DND CALENDAR\checkpoints`; сохранять предыдущие копии и журнал назначения архивов.
4. Исключать из архивов секреты, зависимости, сборки и runtime-базы. Архив исходников не заменяет резервную копию данных.
5. Учитывать мастеров в подборе времени. Хранить моменты в UTC, отображать в выбранном IANA timezone.
6. Вход по логину и паролю без email. Проверять административные и кампанийные права на сервере.
7. Перед выполнением запроса формулировать рабочую задачу на английском; сообщать пользователю о ходе и результате по-русски. Перевод показывать только по запросу.
8. Обновлять [[Текущее состояние]], затронутые заметки и [[Ведение библиотеки|журнал знаний]] в ходе дальнейшей работы.

Связано: [[Чекпоинты и восстановление]], [[Аккаунты и права]].

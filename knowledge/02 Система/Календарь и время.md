# Календарь и время

Участник выбирает кампанию, отмечает доступность в своём поясе и ищет общие интервалы на заданную длительность. ДМ подтверждает подходящее предложение.

## Инварианты

- В подборе участвуют все члены кампании, включая ДМов. Совмещение ролей не создаёт второго участника.
- Моменты хранятся как UTC timestamps в миллисекундах; IANA timezone задаёт ввод и отображение.
- Соседние свободные интервалы объединяются; назначенные сессии исключаются из доступного времени.
- Начало предложения округляется вперёд к 15 минутам.
- Подписи поясов показывают разницу относительно МСК. Для события разницу вычисляют на его дату с учётом DST.
- При ручном вводе повторяющегося осеннего часа выбирается первое вхождение. Несуществующий весенний час отклоняется. Выбранное готовое предложение сохраняет свой точный UTC-момент.
- Ночная сессия отображается на всех занятых локальных датах; конец ровно в полночь не занимает следующий день.

Пример из документации: 10:00 в Москве и 12:00 в Екатеринбурге — один момент.

## Ближайшие предложения

В панели «Час приключений» по умолчанию показаны ближайшие окна, в которых отсутствуют не более двух участников. Участник считается доступным, только если его объединённые свободные интервалы покрывают всю длительность сессии. Мастер учитывается наравне с остальными; окно без мастера явно показывает его имя среди отсутствующих. Окна без доступных участников не предлагаются.

Галочка «Только когда смогут все» переключает предложения на полный состав. Для неполного состава указаны «Могут N из M» и имена без подходящего свободного времени; отсутствие отметок не считается подтверждённой занятостью. Календарные отметки общего времени продолжают обозначать только полный состав. Фильтр хранится в состоянии открытой страницы. Неполные варианты служат для согласования: нажатие показывает уведомление; назначение по-прежнему допускается только для полного состава и проверяется сервером. Назначенные сессии исключаются в обоих режимах.
